Array methods (map, filter, reduce, forEach); iteration patterns; when to use which. Builds on Chapter 3.10 (Arrays). Next: Chapter 3.18 (Template Literals).

## Learning Objectives

- Use array methods: map, filter, reduce, forEach and know when each is appropriate.
- Understand iteration patterns (transform, filter, accumulate) and avoid mutating while iterating.
- Relate array methods to homestead data (sensor lists, logs, config arrays).

---

## 1) map, filter, reduce

- [Expand: map: transform each element; returns new array. filter: keep elements that pass a test; returns new array. reduce: single value from array (sum, max, group).]
- [Expand: forEach for side effects only; no return value used. When to use which; chaining map/filter/reduce.]

- [Expand: homestead: filter sensor readings by threshold, map to display values, reduce for totals.]

## 3) Iteration Patterns and Pitfalls
