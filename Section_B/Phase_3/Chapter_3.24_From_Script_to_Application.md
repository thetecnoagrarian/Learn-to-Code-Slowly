## 1) Script vs Application

- [Expand: script: single entry, linear flow, maybe one or two async steps. Application: ongoing state, event-driven, multiple entry points, persistence or server.]
- [Expand: homestead: from "fetch sensors once and log" to "dashboard that updates every N seconds and handles user actions."]
